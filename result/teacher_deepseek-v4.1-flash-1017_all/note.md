按投诉收件时间（UTC）划分，全量指标由 12,196 条合并后重算。准确率和有效率均以分区内全部样本为分母，最终无效输出计错。Macro-F1 和宏平均召回率对 A–E 五类等权。分类指标以 CFPB 的消费者自选类别为参照。叙述中同时涉及多个问题时，消费者自选类别可能与提示词定义的主要问题不同。 [实验设计](../../Experiment%20Design.md) · [原始全量指标](../../output/baseline_v3/teacher_deepseek-v4.1-flash-1017_all/metrics.json)

- **History**。9,159 条里有 **9,155 条合法 Teacher 标签可用于 Student 训练**，其中 1,942 条（21.21%）与 CFPB 参考不同。B 在参考标签中有 660 条（7.21%），Teacher 只输出 249 条 B，占合法监督的 2.72%。660 条参考 B 中有 292 条被分到 C、133 条被分到 A。
- **Validation**。B 类答对 35/84，召回 **41.67%**、F1 **0.5512**，均是三个分区中最高。C↔D 两个方向共混淆 80 条，占 217 条未答对样本的 36.87%。
- **Test**。B 类答对 39/149，65 条被分到 C，28 条被分到 A。B 类 F1 从 validation 的 0.5512 降到 0.3611，是 macro-F1 下降的主要来源。C 类答对 1,079/1,204，D 类答对 316/389。C↔D 仍是最大的双向混淆，合计 152 条，占 416 条未答对样本的 36.54%。

### 类别占比对准确率的影响

合法 history Teacher 标签中，C 出现最多（5,496/9,155），因此固定预测 C 作为多数类基线。重加权准确率用 history 的 **CFPB 参考类别占比** 作为固定权重，对每个分区的 A–E 召回率求加权平均。

| 分区 | 常量 C 准确率 | 常量 C Macro-F1 | Teacher 准确率提升 | 按 history 类别占比重加权的 Teacher 准确率 |
| --- | ---: | ---: | ---: | ---: |
| history | 55.91% | 0.1434 | +22.84 个百分点 | 78.75% |
| validation | 55.48% | 0.1427 | +23.10 个百分点 | 79.13% |
| test | 59.49% | 0.1492 | +19.96 个百分点 | 79.22% |

从 validation 到 test，C 在参考集的占比由 **55.48%** 升到 **59.49%**，且两个分区的 C 召回都接近 90%。原始准确率相差 **0.87 个百分点**。固定类别占比后，差距缩到 **0.09 个百分点**（79.13% 对 79.22%）。原始准确率的提升主要随类别构成变化，macro-F1 则显示 B 类表现出现了明显下滑。
