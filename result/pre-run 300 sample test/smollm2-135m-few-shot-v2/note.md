# 五示例提示词对 SmolLM2 的影响

2026-11-22 · 同一批 300 条开发集投诉 · 原装 SmolLM2-135M-Instruct

v2 用五轮独立的“投诉 → 单字母”问答示范 A–E，每类一个自拟示例。系统消息给出分类边界和错误输出格式，每条投诉结尾以 `Category (one letter):` 提示作答。模型权重、输入正文、贪心解码和 16 个输出 token 的上限与 v1 相同。[完整提示词](../../../code/prompts/mortgage_v2.toml)

| 版本与读法 | 有效标签 | 与 CFPB 一致 | 五类 macro-F1 |
|---|---:|---:|---:|
| v1，自由生成 | 1/300 | 1/300（0.33%） | 0.0023 |
| v1，首个 token 限定五选一 | 300/300 | 39/300（13.0%） | 0.0643 |
| v2，自由生成 | 300/300 | 42/300（14.0%） | 0.0922 |

v2 的 300 条首次回复均为合法字母，且都与首个 token 五选一的结果一致。模型预测了 206 个 A、9 个 B、9 个 C、76 个 D、0 个 E。格式合规率提高到了 100%，五选一读法下答对的投诉只增加了 3 条。

提示词开发时用 seed 42 从这 300 条中按 A–E 顺序每类随机取 5 条比较写法。最终版本在这 25 条上答对 7 条，在其余 275 条上答对 35 条（12.7%）。这些是开发集结果。

Gemma 用同一版提示词完成了 300 条推理，随后在本地重新运行了 SmolLM2。两者在 36/300 条上选了相同标签，一致率为 12.0%。[配对实验记录](../gemma/v2/note.md) · [逐条回复](predictions.csv) · [完整指标](metrics.json) · [v1 对照实验](../smollm2-135m-zero-shot/note.md)
